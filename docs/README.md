# AI Coach Documentation

Welcome to the documentation home for AI Coach. These guides explain how to set up the project, understand its Cosmos DB-centered architecture, work with the service API, and contribute safely.

## Available Documentation

- [Getting Started](getting-started.md) — Install dependencies, configure Cosmos DB access, run AI Coach locally, and validate the setup.
- [Architecture Overview](architecture.md) — Review the current TypeScript/Cosmos DB design, data flow, and future scaling considerations.
- [API Reference](api-reference.md) — Learn the `CosmosService` API, configuration types, and common usage patterns.
- [Development Guide](development-guide.md) — Follow the local development workflow, scripts, conventions, and contributor practices.
- [Security Practices](security-practices.md) — Understand how AI Coach handles secrets, dependency hygiene, CI security checks, and Cosmos DB hardening.

## Suggested Reading Path

1. Start with [Getting Started](getting-started.md)
2. Continue with [Architecture Overview](architecture.md)
3. Keep [API Reference](api-reference.md) open while building against Cosmos DB
4. Review [Development Guide](development-guide.md) before opening a pull request
5. Read [Security Practices](security-practices.md) before handling credentials or deployment settings
