# Security

Microsoft takes the security of this project seriously. If you believe you have found a security vulnerability, please report it to the Microsoft Security Response Center (MSRC) at [https://msrc.microsoft.com/create-report](https://msrc.microsoft.com/create-report).

Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.

## Reporting a Vulnerability

When submitting a report, please include detailed reproduction steps, affected components, impact, and any relevant proof-of-concept information to help us investigate.

- Preferred language for vulnerability reports: English
- Disclosure process: Microsoft follows its [Coordinated Vulnerability Disclosure](https://www.microsoft.com/en-us/msrc/cvd) policy
- Bug bounty information: See the [Microsoft Bug Bounty Program](https://www.microsoft.com/en-us/msrc/bounty)

We will acknowledge receipt of your report, investigate the issue, and work with you to understand and remediate the vulnerability.
