##### Overview

Global Address Book or GAB is a Microsoft-published solution set for Global Address Book (GAB) synchronization. Delivered as managed solutions via Power Platform Admin Center

It bridges:

- Dynamics 365 Finance & Operations (F&O)
- Dataverse / CE

##### Uses:

- Dual-write entity maps
- Plugin assemblies (Dynamics365GABExtended)

##### Dual-write issues

- sync failures
- loopbacks
- data corruption scenarios

This are owing to

- Plugin issue
- Entity mapping issue
- Sync pipeline issue Or
- telemetry gap

##### Requirement

Bulk of the observed issues are owing to the customization undertaken by the customers and their partners and the failure to use the Trouble Shooting Guides(TSG) appropriately. Build an AI assisted tool that accelerates the build and deployment of a GAB dual write solution but also helps the implementer to quickly understand and remediate issue during development and also production without having to always wait for the product team's help.
