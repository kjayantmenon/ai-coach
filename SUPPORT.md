# Support

## How to Get Help

- **Bugs and feature requests**: Open a GitHub Issue in this repository.
- **Questions and discussions**: Use GitHub Discussions for usage questions, architecture conversations, and general support.
- **Documentation**: Check the project documentation in the [docs/](docs/) folder.

## Before Opening a Request

Please search existing issues and discussions before creating a new one to avoid duplicates. When reporting bugs, include clear reproduction steps, expected behavior, actual behavior, and relevant environment details.

## Security Issues

Do not report security vulnerabilities through GitHub Issues or Discussions. Please follow the guidance in [SECURITY.md](SECURITY.md).
